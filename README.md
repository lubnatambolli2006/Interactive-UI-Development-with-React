# Interactive UI Development with React

## React To-Do List

This project demonstrates the fundamentals of React by creating an interactive To-Do List application.

## Technologies Used

- React JS
- HTML5
- CSS3
- JavaScript

## React Concepts Demonstrated

### Components
The application is divided into reusable components:
- App
- TodoList
- TodoItem

### State Management
The `useState` hook is used to manage:
- The current task
- The list of tasks

### Props
Props are passed between components to provide task data and handle delete operations.

### Event Handling
The application handles:
- Button clicks
- Keyboard Enter events
- Input changes

## Features

- Add new tasks
- Delete tasks
- Display all tasks
- Prevent empty tasks
- Press Enter to add a task
- Responsive design
- Mobile-friendly interface
